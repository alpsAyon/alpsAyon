## 📌 Featured projects

| Project | Description | Stack |
|---|---|---|
| [Blood Component Wastage Simulation](https://github.com/alpsAyon/blood-wastage-sim) | **MSc Dissertation.** Discrete event simulation modelling Cold Stored Platelet wastage for Wales Blood Service — tracking ~300 units/year through Storage → Helicopter → Used/Waste states across 4 EMRTS bases. Assessed whether pre-mixed products increase wastage and risk of stock depletion. | Python / SimPy, R / simmer |
| [NHS Prescription Cost Analysis](https://github.com/alpsAyon/nhs-prescription-analysis) | Processed 54M+ rows of NHSBSA English Prescribing Data (Apr–Jun 2025). Memory optimisation reduced footprint from ~32 GB to ~1.8 GB. Covers BNF chapter costs, top drugs, and regional variation across 43 ICBs. | Python, pandas, SQL |
| [COVID-19 Wales Population Health](https://github.com/alpsAyon/covid19-wales-health) | Seven pandemic waves across 22 Welsh local authorities, integrating WIMD 2019 deprivation scores and 2021 census data. CFR declined from ~12.6% to ~1.4%; strong deprivation correlation (r = −0.995). | R, tidyverse, ggplot2, sf |
| [Cognitive Decline Predictor](https://github.com/alpsAyon/cognitive-decline-predictor) | Multiple regression with VIF diagnostics (severe collinearity in Age/BMI). Physical activity was the only significant lifestyle predictor; includes APOE4 interaction model. | R, ANOVA, regression |
| [NHS Medicines Waste Simulation](https://github.com/alpsAyon/nhs-medicines-waste-sim) | DES of the dispensing-to-ward medicines waste pipeline using OpenPrescribing API data. Extends dissertation methodology to community prescribing. | R, simmer |
| [CVD Prediction ML](https://github.com/alpsAyon/cvd-prediction-ml) | Cardiovascular disease prediction model achieving 91% accuracy — BSc final year project. | Python, scikit-learn |
